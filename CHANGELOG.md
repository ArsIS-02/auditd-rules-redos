# Изменения

## 1.6 — 2026-10-24

- Исключение для крона GLPI: `/usr/bin/php` от пользователя apache на каждом
  запуске безуспешно открывает `/etc/krb5.keytab`, что давало около 940 записей
  `unauthorized_access_attempt` в сутки с одного хоста. Добавлено правило
  `never` перед общим правилом по `/etc`, суженное до одного файла и одной
  программы: любое другое обращение по-прежнему записывается.
- Правил стало 56 (aarch64) и 61 (59 без SELinux) для x86_64; счётчики
  обновлены в заголовках файлов, README и тестах.
- `docs/HISTORY.md`: раздел 8 — разбор случая, проверенные и отброшенные
  версии (LDAP, `php-imap`, трассировка Kerberos) и обоснование выбранного
  вида исключения.

## 1.5 — 2026-10-22

Первая публикация.

- Свод правил для aarch64: 55 правил, проверен на 4 хостах РЕД ОС (audit 3.1.3).
- Свод правил для x86_64: 60 правил (58 без SELinux), имена syscall сверены
  с таблицами audit-userspace; на живом хосте ещё не подтверждён.
- Сокеты и файловые операции записываются только в пользовательских сессиях
  (`auid>=1000`, `auid!=-1`).
- Убраны: правила `subj_type` для хостов без SELinux, исключение по UID
  chronyd, исключение для `/dev/shm`.
- x86_64: добавлены `renameat2` в `file_deletion` и ключ `file_creation`
  (как на aarch64).
- `deploy/deploy.sh`: проверка файла до загрузки, резервная копия, сверка
  числа правил, автоматический откат.
- `deploy/verify.sh`: проверка загруженного набора и тестовые события.
- Правила Wazuh и pipeline для Graylog.
